# Componentes e origem

Xui Naxx 1.5.14 identifica esta edição de interface, tradução e ferramentas. A base do núcleo é XUI 1.5.12.

## Referências

- [PabloServers/xui.one](https://github.com/PabloServers/xui.one)
- [amidevous/xui.one](https://github.com/amidevous/xui.one)

O instalador preserva o fluxo dos componentes da referência e verifica os hashes fixados antes de aplicá-los. O núcleo completo permanece fora do histórico Git. Os arquivos originais e seus avisos pertencem aos respectivos titulares; esta edição não atribui uma nova licença aos componentes de terceiros.

O painel usa PHP, nginx, Redis, MariaDB e bibliotecas de interface. Preserve os avisos distribuídos com cada dependência.

O canal público de atualização contém somente os arquivos próprios de interface e integração. Credenciais, banco de dados e arquivos particulares de cada instalação ficam fora do pacote.
